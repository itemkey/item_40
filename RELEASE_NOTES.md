## 0.5.0

- Новый раздел Telegram с инструментом «Скачать эмодзи».
- Подключение своего бота через токен @BotFather. Подключение сохраняется с шифрованием Windows DPAPI.
- Загрузка пака по ссылке, выбор эмодзи по миниатюрам и сохранение исходных WEBP, TGS и WebM.
- Отмена, сохранение готовых файлов и повторная попытка для неудачных загрузок.

Для установки или обновления скачайте файл `*-setup.exe` и запустите его. Предыдущую версию удалять не нужно. История, настройки и модели сохраняются.

ZIP — версия без установки. Для её обновления закройте приложение и замените папку программы содержимым нового архива.
